# Screenshot assets

Use these exact filenames so the README snippets can be enabled without editing paths.

## Required

### `01-selection.png`

Screenshot the ChatGPT page while selecting one mixed block containing:

- ordinary prose;
- one inline equation;
- one display equation.

The selection highlight must be visible.

### `02-typora-source.png`

Paste the same selection into Typora **source code mode**.

The screenshot must clearly show:

```text
$...$
```

and:

```text
$$
...
$$
```

This proves the output is real Markdown/LaTeX rather than rendered rich text.

## Recommended

### `03-before-after.png`

A compact comparison:

- left: broken native copy result;
- right: script result with clean Markdown + LaTeX.

This is the best screenshot for the repository social preview / Reddit / V2EX posts.

## Screenshot hygiene

- Crop tightly.
- Do not expose private conversation content.
- Use a simple mathematical example.
- Do not include browser account identifiers.
- Keep text readable at GitHub README width.
